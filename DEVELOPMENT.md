# Development Guide: RoomCraft

## 1. Local Environment Setup
Ensure prerequisites (React, TypeScript, Three.js, React Three Fiber, Zustand) are installed.
```bash
npm install
npm run dev
```

## 2. Code Standards
- Strict TypeScript checking (`noImplicitAny: true`).
- Clean separation between pure logic and UI presentation.
- Conventional Commits: `feat:`, `fix:`, `test:`, `docs:`, `refactor:`, `chore:`.
